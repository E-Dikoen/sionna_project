# sionna_project
Sionna是一个用于通信系统设计与仿真的开源库，该库基于tesorflow库用python开发。Sionna包括主要的通信模块，如调制（MPSK、MQAM等）、信道编码（LDPC码、Polar码等）、无线信道模型等，此外该库还包括基于自编码器的端到端的通信系统模块，可以通过神经网络完成端到端的通信系统设计与仿真。 本课题的目标是基于Sionna库完成本科课程设计的课程开发，并用于课程设计的教学。内容包括常见的同学系统的开发，如多载波（OFDM）通信系统设计与仿真、MIMO通信系统的设计与仿真、直接序列扩频（DSSS）通信系统的设计与仿真等。
